Solmar Heat — an original open-world crime game set in the sun-soaked city of Solmar. Rico Vega, a driver for the fixer Mara Sol, steals cars, loses the Solmar PD, and runs five story missions: Wheels for Rico, The Pickup, Lose the Heat, Rush Hour, and The Big Score. Top-down 2D, plain canvas, no libraries, no network: traffic and pedestrians, a wanted level with chasing police, combat, a HUD with a minimap, a start screen, pause, and save/load.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD move/drive, mouse aim, click shoot, E steal/enter a car, Shift run, P pause, M mute.
